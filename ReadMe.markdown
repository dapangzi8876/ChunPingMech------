【淳平机械体 MOD——第一阶段基础实现规格】

一、当前阶段目标

本阶段只完成淳平机械体最基础、最稳定的功能。

目标是让所有机械体能够：

1. 正常加载 Def
2. 正常生成
3. 正常显示
4. 正常归属玩家机械师
5. 正常执行指定工作
6. 战斗型机械体拥有基础攻击能力
7. 正常受伤、倒地、死亡
8. 正常进入机械体制造系统
9. 按科技等级解锁
10. 正常消耗带宽
11. 具有合理的基础数值
12. 为以后添加技能和特殊机制保留扩展空间

当前阶段不要实现：

- 主动技能
- Ability
- 特殊技能按钮
- 霸凌
- 斩首
- 隐身
- 雪之呼吸
- EMC
- 做局陷阱
- 诱饵召唤
- 早稻田冲锋
- 大粪地狱
- 战争女皇召唤
- 魔王炮特殊蓄力机制
- 特殊护盾机制
- 特殊处决逻辑
- 特殊 AI 行为
- 敌对淳平袭击
- Boss机制
- 特殊 C# 技能系统

这些内容全部留到后续阶段。


============================================================
二、贴图处理原则
============================================================

当前所有淳平机械体暂时使用 RimWorld 原版机械体贴图作为占位。

作者之后会自行制作并替换正式淳平贴图。

因此当前开发不要在贴图方面投入过多工作。

现阶段可以统一使用：

<texPath>Things/Pawn/Mechanoid/Fabricor</texPath>

以及：

<maskPath>Things/Pawn/Mechanoid/AllegianceOverlays/Mech_Fabricor</maskPath>

Shader 根据原版 Fabricor 的正确写法处理。

优先使用：

<shaderType>CutoutWithOverlay</shaderType>

当前 texPath、maskPath、drawSize 都属于临时数据。

程序结构必须保证作者以后只修改贴图字段，就可以替换外观，而不用修改单位功能。

============================================================
八、科技实现原则
============================================================

现阶段优先完成最简单可用的科技解锁。

不要一次开发复杂的淳平独立科技树。

可以先建立四个淳平研究项目，例如：

ChunPing_BasicMechtech
ChunPing_StandardMechtech
ChunPing_HighMechtech
ChunPing_UltraMechtech

对应中文：

淳平基础机械工程
淳平标准机械工程
淳平高级机械工程
淳平终极机械工程

它们必须同时依赖对应的 RimWorld 原版机械科技。

逻辑：

原版基础机械科技
+
淳平基础机械工程
=
允许制造基础淳平。

原版标准机械科技
+
淳平标准机械工程
=
允许制造标准淳平。

原版高级机械科技
+
淳平高级机械工程
=
允许制造高级淳平。

原版终极机械科技
+
淳平终极机械工程
=
允许制造终极淳平。

如果实际原版 DefName 不确定：

必须检查游戏原版 Def。

禁止凭记忆直接猜 DefName。


============================================================
九、机械体制造
============================================================

所有淳平机械体需要接入正常机械师制造体系。

根据原版机械体机制设置：

- gestationCycles
- bandwidthCost
- gestationComplexity
- mechWeightClass
- 所需材料
- 是否需要对应芯片
- 制造时间
- 相关 Recipe / MechGestationRecipe

第一阶段尽量参考同等级原版机械体进行数值设计。

例如：

基础工作型淳平
→ 参考轻型工作机械体。

警察淳平
→ 参考标准远程战斗机械体。

绿巨人
→ 参考重型机械体。

雷奥、贝尔泽布布、魔王
→ 参考终极/超重型机械体。

不要直接复制所有数值。

重点保持大致同科技阶段平衡。


============================================================
十、第一阶段暂定数值设计原则
============================================================

基础机械科技：

低带宽。
低至中低成本。
低耐久。
工作效率是核心。


标准机械科技：

中等带宽。
中等成本。
开始出现正式战斗单位。


高级机械科技：

较高带宽。
较高成本。
明显专业化。
基础数值明显强于标准机械科技。


终极机械科技：

高带宽。
极高制造成本。
高生命。
高护甲。
强战斗力。
不适合大量制造。
